# CS Legends — 产品需求文档（v1：ZywOo）

## 1. 背景与目标

做一个「CS 传奇选手生涯地图」网站：进入站点即是一颗可拖拽旋转、可缩放的三维地球，球面按国家分块；鼠标悬停某个国家时该国家高亮，右侧直接列出该选手在这个国家参加过的全部赛事，以及每届赛事的主办方、场馆、成绩和打过的**全部比赛**。

v1 先交付 **ZywOo（Mathieu Herbaut）**，但页面结构按「可切换选手」设计，左上角常驻选手选择器，后续新增选手不需要重做页面。

成功标准：
- 打开站点即进入三维地球，没有登录、时间线、Hero、荣誉墙等干扰内容。
- 用户能在 3 步内完成「选选手 → 找赛事 → 看该届全部比赛」。
- 新选手只新增数据文件与选择器条目即可复用同一套地球。

## 2. 目标用户

| 用户 | 诉求 |
| --- | --- |
| CS 赛事观众 | 按地点回看选手的生涯轨迹，了解每届赛事的过程而不只是决赛 |
| 内容创作者 | 通过 JSON API 获取带逐场赛果的结构化数据 |

## 3. v1 范围

### 3.1 功能需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-1 | 全屏三维地球 | 地球铺满视口，按国家分块渲染；支持拖拽旋转、滚轮 / 双指缩放；暗色夜景海洋 + 绿色大气层；默认缓慢自转 |
| FR-2 | 选手选择器 | 左上角常驻；点击展开选手列表；当前仅 ZywOo，其他选手可后续追加 |
| FR-3 | 国家高亮 | 鼠标悬停国家时该国家变绿并抬升；移出后恢复默认色；举办过赛事的国家默认底色比其他国家略亮 |
| FR-4 | 国家信息 | 悬停或点按国家，右侧（移动端为底部）面板直接展示该国全部赛事：国家名、赛事/场次统计，以及每届赛事的日期、地点、场馆、主办方、成绩、简介与**本届全部比赛**（阶段、对手、比分、胜负）；**单击后面板保持固定**，鼠标移出不关闭，便于阅读同国多届赛事 |
| FR-5 | 数据 API | `GET /api/players/zywoo` 返回档案、统计与事件数组，事件含 `organizer`、`matches` |
| FR-6 | 主办方标记 | 每个举办过线下赛事的国家显示该国**全部主办方**的小图标（如德国同时显示 ESL 与 SL），单主办方多届标出届数；标记不拦截鼠标，悬停图标区域仍高亮所在国家；放大地球后密集区域的重叠标记逐一分开 |
| FR-7 | 基础账号 | 注册 / 登录 / 退出 / 账号页 / `GET /api/me`；OAuth2 密码模式，浏览器用 HttpOnly Cookie、API 用 bearer 令牌；密码 argon2id 哈希；登录失败不区分「账号不存在」与「密码错误」；表单提交带 CSRF；同一 identifier 或 IP 15 分钟内失败 5 次返回 429；「退出所有设备」通过 `token_version` 让已发出的 access token 立即失效。**不含**邮箱验证、找回密码、第三方登录，也不含任何需要登录的业务功能 |

### 3.2 非目标（v1 不做）

- 时间线、荣誉墙、首页统计卡、赛事筛选 chips（本版已移除）。
- 账号的周边能力：第三方 OAuth（Google / GitHub 等）、邮箱验证、找回密码 / 改密流程、多角色管理后台。
- 需要登录的业务：评论、点赞、收藏、后台管理。
- 多选手内容（选择器结构已预留，但只录入 ZywOo）。
- 移动端原生 App、离线地图瓦片。

## 4. 数据口径

- 赛事范围：2019–2026 年共 **84 条**生涯记录，其中 **82 条**为线下/线上赛事，**2 条**为生涯里程碑（出生、加入 Vitality）。
- 82 条赛事全部含 `organizer` 与 `matches`；逐场赛果共 **398 场**，覆盖小组赛/瑞士轮/淘汰赛，不只是决赛；赛果截至 2026-11-15。
- 线上赛（2020 年 IEM Beijing、BLAST Fall）保留在 API 中，但不出现在地图上；80 条赛事带坐标，覆盖 22 个国家/地区。
- 地球按国家聚合：同一城市的多届赛事统一归入该国面板，按时间顺序列出，不存在标记重叠问题。
- 主要来源：Liquipedia、HLTV、ESL / BLAST / StarLadder / PGL 官方赛事页。
- 数据文件：`src/cs_player/data/zywoo.json`，每条事件带 `source` 字段。
- 文案为中文，赛事名保留英文原名，便于检索。

## 5. 关键假设

- [假设] 部署环境可访问 jsDelivr（Globe.gl）；地球纹理本地化，无网络时 3D 地球无法渲染，页面降级为深空底色与提示。
- [假设] 用户浏览器支持 WebGL；不支持时给出文字提示。
- [假设] v1 为单机/小型部署；内容数据以 MySQL 为准、JSON 兜底，账号数据也在同一个库；「登录之后做什么」尚未定义，因此登录态先独立存在。
- [假设] 用户接受中文界面；桌面端以悬停为主，触屏端以点按为主。

## 6. 验收清单

1. `uv run uvicorn cs_player.app:app --port 8000` 可启动。
2. `/` 返回 200，页面只包含全屏三维地球与左上角选手选择器，不出现登录或个人页入口。
3. 地球可拖拽旋转、滚轮缩放；国家按块渲染，悬停国家时高亮并抬升；默认缓慢自转。
4. 举办过赛事的国家显示该国全部主办方小图标（如德国 ESL+SL），图标上可读；滚轮放大后密集区域图标不重叠；悬停图标所在国家仍能高亮。
5. 悬停任一有赛事的国家（如法国、瑞典）出现右侧面板；单击后鼠标移到海洋，面板保持显示该国全部赛事；按 Esc 或点击 `×` 后关闭。
6. 点击选手选择器可展开/收起选手列表；当前仅 ZywOo。
7. 页面右上角有账号入口：未登录显示「登录」，登录后显示用户名与下拉菜单（账号页 / 退出）。
8. `GET /api/players/zywoo` 返回 JSON，84 条记录中 82 条赛事含非空 `organizer` 与 `matches`（共 398 场），赛果截至 2026-11-15。
9. 账号链路成立：注册 → 登录 → `/api/me` 返回到当前用户 → 刷新令牌轮换可用 → 重复使用旧刷新令牌被拒且该用户 access token 全部失效 → 退出后 `/api/me` 返回 401；`/account` 未登录时 302 到 `/login?next=/account`；数据库中不存在明文密码（`password_hash` 以 `$argon2id$` 开头）。
10. `GET /login`、`GET /register` 返回 200；表单缺少或伪造 `csrf_token` 时返回 403；同一账号连续 5 次密码错误后返回 429。
