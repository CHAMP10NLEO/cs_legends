# 设计规范（v1）

## 1. 概念

「一颗会说话的地球」：进入站点只有一颗可拖拽旋转的三维地球，球面按国家分块，所有内容都由悬停的国家触发。暗色、克制、电竞感，不使用选手照片，避免版权风险。

关键词：深空黑、瞄准镜绿、奖杯金、国家描边、等宽数字、全屏沉浸。

视觉原则：**三维地球是唯一的页面骨架，除左上角选手选择器外不叠加任何常驻内容。**

参考方向：HLTV 的赛事密度感、Valve Major 转播的深色舞台感。

## 2. 页面结构

### 首页 `/`（全屏三维地球）

1. 左上角 HUD：
   - 选手选择器按钮：头像字、ID、战队 · 国籍、下拉箭头。
   - 点击展开选手列表；当前仅 ZywOo，选中项标「当前」；底部「更多传奇选手筹备中」。
   - 按钮下方一行操作提示：拖拽旋转 · 滚轮缩放 · 悬停国家查看赛事。
2. 右上角不设账号入口，页面不出现登录、注册或个人页链接。
3. 地球：铺满视口，按国家分块，举办国显示主办方小图标；暗色夜景海洋 + 绿色大气层，鼠标悬停国家时高亮，默认缓慢自转。
4. 国家信息面板：
   - 桌面：右侧浮层，宽 400px，最大高度 `calc(100% - 124px)`，可滚动。
   - 移动端：底部抽屉，最大高度 58vh，圆角只在顶部。
   - 内容：国家名、赛事/场次统计；该国每届赛事的日期 · 城市、赛事名、成绩徽章、主办方、场馆、简介、本届全部比赛列表（阶段 / 对手 / 比分 / 胜负）。
   - 未悬停时隐藏；`×` 关闭；按 Esc 关闭。
5. 无网络或 Globe.gl 加载失败：保留深空底色，居中提示「3D 地球加载失败，赛事信息仍可查看」。

> 本期不包含登录页与个人页；`/login`、`/me` 不注册路由（404）。

## 4. 三维地球

- 库：Globe.gl 2（jsDelivr CDN），底层 Three.js。
- 底图：`earth-night.jpg`（海洋夜景）+ `earth-topology.png` 凹凸，本地静态资源；大气层青色（`#5eead4`，`atmosphereAltitude 0.13`），页面底色为深空渐变。
- 国家分块：`static/data/countries.geojson`（Natural Earth 110m，补充 50m 的马耳他）共 177 个国家/地区面，每块为独立多边形，曲率细分 3°。台湾地区并入「中华人民共和国」要素（同一 MultiPolygon 的独立环），不单独成国。
  - 默认：面 `rgba(28,48,66,0.72)`（半透明，透出夜景纹理），侧面 `rgba(20,38,54,0.7)`，描边 `rgba(94,234,212,0.14)`，海拔 0.004。
  - 悬停：面 `rgba(74,222,128,0.34)`，侧面 `rgba(74,222,128,0.36)`，描边 `rgba(167,243,208,0.95)`，海拔抬升到 0.018。
  - 海拔切换动画 260ms（`polygonsTransitionDuration`），避免悬停时突兀跳变。
- 举办国底色：有赛事的国家默认面 `rgba(44,84,106,0.9)`、描边 `rgba(94,234,212,0.38)`，比无赛事国家略亮，未悬停时也能一眼看出哪些国家举办过比赛。
- 球体质感：
  - 材质 `shininess 8`、高光色 `#24384a`，让海洋有细腻反光；
  - 灯光：环境光 3.8、主平行光 2.2，另加一盏 `#5eead4` 轮廓光（强度 0.5，自左后下方），让球体边缘有体积感；
  - 背景：CSS 生成的深空星空点阵 + 三层低透明度色雾，地球外围 34%–100% 叠加径向暗角，使球体从深空中浮出；
  - 画布首帧渲染后 800ms 淡入，避免纹理加载前的空球闪烁。
- 主办方标记：每个举办过线下赛事的国家一枚小标记，位置取该国最近一届赛事的城市。
  - 内容：该国出现过的**全部主办方**缩写并列展示 —— ESL / BLAST / PGL / SL（StarLadder）/ BTS（Beyond the Summit）/ FACEIT / EPIC（Epic Esports Events）/ G8（Gamers8），按届数降序排列。
  - 配色：ESL `#4f9cf9`、BLAST `#f5c451`、PGL `#f472b6`、StarLadder `#f87171`、Beyond the Summit `#34d399`、FACEIT `#fb923c`、Epic Esports Events `#a78bfa`、Gamers8 `#2dd4bf`；深色胶囊底 + 同色描边与文字，不加彩色外发光。
  - 徽标左侧 4px 同色锚点圆点指向真实坐标，整组右移 9px，避免胶囊遮住坐标点。
  - 同一主办方在该国举办多届时，徽标右上角显示届数（如 `ESL 2`）。
  - 标记 `pointer-events: none`，不拦截鼠标，悬停仍命中所在国家。
  - 位于地球背面的标记隐藏；屏幕空间过近的标记暂时隐藏，去除欧洲等密集区域的重叠，滚轮放大后逐一分开展示。
- 初始视角：
  - 桌面：`lat 24 / lng 18 / altitude 2.0`。
  - 移动端（宽度 < 600px）：`altitude 2.6`。
  - 相机距离 120–480；滚轮 / 双指缩放，拖拽旋转，禁用平移。
- 自动旋转：默认开启（`autoRotateSpeed 0.32`）；悬停国家或打开详情时暂停，离开后 4 秒恢复；拖拽期间暂停。
- 光标：默认 `grab`，按住 `grabbing`，悬停在有赛事的国家上为 `pointer`。
- 交互：
  - 悬停国家 → 高亮该国家，右侧面板直接显示该国全部赛事（日期、赛事名、成绩、主办方、场馆、简介、逐场赛果）。
  - 单击国家 → 固定该国面板：鼠标移出后面板保持显示，可慢慢阅读同国的多届赛事；再次悬停其他国家不会顶掉已固定的面板。
  - 取消固定：点击海洋 / 球体空白、点击 `×`、按 Esc（同时关闭选手菜单）。
  - 移动端点按国家 → 底部抽屉，行为与单击固定一致。
- 数据匹配：`zywoo.json` 的 `country`（中文）与 GeoJSON `NAME_ZH` 对齐；`阿联酋 → 阿拉伯联合酋长国` 为别名；仅统计含 `organizer` 的赛事，`欧洲赛区` 等线上赛区不参与匹配。
- 降级：Globe.gl 未加载、WebGL 不可用或国家数据加载失败时显示文字提示，页面保留深空底色。

## 5. 国家信息面板

### 状态

| 状态 | 表现 |
| --- | --- |
| default | 隐藏，不占位 |
| open | 悬停 / 点按国家时出现，内容淡入 120ms |
| no events | 显示「ZywOo 暂无在该国的赛事记录。」 |
| no matches | 单届赛事无逐场记录时不渲染比赛列表 |
| long list | 面板内部滚动，地球不被挤动 |
| mobile | 底部抽屉，触控目标 ≥ 44px，含 `env(safe-area-inset-bottom)` |

### 内容层级

1. 国家 / 地区（绿色等宽小字）
2. 国家名（22px / 移动端 19px）
3. 统计：`N 届赛事 · M 场比赛`
4. 该国每届赛事（自上而下，分隔线隔开）：
   1. 日期 · 城市 · 国家（绿色等宽小字）
   2. 赛事名（17px）
   3. 成绩徽章：冠军绿、Major 金、其他灰
   4. 主办方 / 场馆（两列信息块，移动端单列）
   5. 一句话故事
   6. 「本届全部比赛」+ 场次与胜负统计
   7. 逐场列表：阶段 76px、对手自适应省略、比分等宽右对齐、胜负 26px

## 6. 响应式（三档）

| 断点 | 布局 |
| --- | --- |
| ≥ 1280px | 地球全屏；左上选手选择器 300px 菜单；右侧详情 400px |
| 768–1279px | 同左，详情面板宽度 `min(400px, calc(100vw - 40px))` |
| < 768px | 详情改为底部抽屉（58vh）；隐藏操作提示；选手菜单宽度 `min(300px, 100vw - 24px)` |

移动端选择器靠左显示；所有按钮最小高度 44px。

## 7. 可达性

- 正文颜色对比 ≥ 4.5:1；次要文字仅用于非关键信息。
- 选手选择器使用 `aria-expanded` / `aria-controls`；详情面板 `aria-live="polite"`。
- 国家多边形由 WebGL canvas 承载，不进入 Tab 顺序；桌面端靠悬停、移动端靠点按命中。
- Esc 可关闭信息面板；关闭按钮有 `aria-label`。
- 动效仅保留 120–150ms 的边框/背景变化，尊重 `prefers-reduced-motion`。
